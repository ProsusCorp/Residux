# Politica de Seguridad

## Versiones soportadas

Actualmente se da soporte de seguridad a la rama principal activa.

## Reporte de vulnerabilidades

Si detectas una vulnerabilidad:

1. No abras un issue publico con detalles explotables.
2. Reporta de forma privada al mantenedor del repositorio.
3. Incluye pasos para reproducir, impacto estimado y entorno.

## Alcance de seguridad en este proyecto

- Configuraciones de red/robot deben mantenerse locales (`config.local.json`).
- No incluir credenciales, tokens ni endpoints privados en commits.
- Revisar dependencias periodicamente para actualizaciones de seguridad.
