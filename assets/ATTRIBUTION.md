# Atribuciones y licencias de assets

Este archivo registra procedencia y licencia de recursos multimedia incluidos o usados por Residux_01.

## Estado actual

- `assets/sprites/*`: revisar y confirmar licencia de cada sprite antes de publicacion final.
- `assets/sounds/*`: revisar licencia de cada efecto de sonido.
- `assets/music/background.wav`: revisar licencia de redistribucion.

## Formato recomendado para nuevos recursos

Usa este bloque por cada asset:

```text
Nombre archivo:
Ruta:
Autor/Fuente:
URL:
Licencia:
Permite redistribucion en GitHub: Si/No
Notas:
```

## Fuentes sugeridas

- Kenney (normalmente CC0): https://kenney.nl/assets
- OpenGameArt (licencia variable): https://opengameart.org/
- Pixabay (ver terminos): https://pixabay.com/
- Freesound (licencia variable): https://freesound.org/

## Importante

No publiques assets sin confirmar que su licencia permite redistribucion publica.
